# Flexi-Time

Flexi-Time is a flexible daily scheduling app that helps you build consistent habits and make time for the things that matter to you. Instead of following a fixed timetable, you choose what to work on and track your progress throughout the day.

## Features

- **Custom Activities:** Create activities with a name, daily time target, and category.
- **Flexible Time Tracking:** Start, pause, and switch between activities whenever you want.
- **Daily Progress:** View your planned, completed, and remaining time.
- **Progress Indicators:** Track your progress toward each activity's daily target.
- **Pomodoro Timer:** Use focused work sessions and short or long breaks.
- **Activity-Linked Focus:** Connect Pomodoro focus sessions to an activity to track your time.
- **Automatic Daily Reset:** Daily progress resets for the next day while your activities remain saved.
- **Local Storage:** Your activities and progress are saved in your browser.
- **Help Guide:** Learn how to use the app directly from the interface.

## Built With

- HTML
- CSS
- JavaScript
- Browser Local Storage

Flexi-Time uses vanilla JavaScript without requiring a framework or build system.

## How to Use

### 1. Create Activities

Click **+ Add Activity** and enter an activity name, daily target in minutes, and category.

### 2. Track Your Time

Click **Start** on an activity card to begin tracking. Click **Pause** to stop, or start another activity when you want to switch tasks.

### 3. Monitor Daily Progress

Use the daily summary and individual activity cards to see how much time you have completed and how much remains.

### 4. Use the Pomodoro Timer

Choose **Focus**, **Short Break**, or **Long Break**. Select an activity before starting a focus session. Focus time contributes to the selected activity's progress, while break time is not counted as activity time.

When a session ends, the app plays a notification and waits for you to start the next session.

## Data and Privacy

Flexi-Time stores activity data in your browser using Local Storage. Data is associated with the browser and website origin where the app runs, so it does not automatically synchronize between devices or browsers.

Clearing the browser's site data may erase saved activities and progress. Consider keeping a backup if the information is important.
